# CHANGELOG

## [1.0.1] - 2026-11-07

### 변경 내용
- **항해 모드 3종 및 경제 밸런스 개편**:
  - 초기 크레딧을 `3,500 CR`로 조정하여 초반 자금 압박 및 전략적 항해 선택 유도.
  - 3D 직접 조종 항해(`MANUAL`, WASD/화살표 + 부스트), 고가 소모품인 워프 점프 셀(`WARP`), 워프보다 저렴한 횟수 제한형 `AI Autopilot Agent`(`AI_AGENT`) 구현.
- **행성별 상점 및 구역별 우주지도·아이템 시각화**:
  - 10개 구역(`Sec.1`~`Sec.10`) 기간제 우주지도 및 항해 중 무지도 상태 긴급 구매(상점 정가의 10배, 계정당 최대 3회 제한) 구현.
  - 행성마다 판매 품목이 다른 상점 카탈로그 및 `Lv.1`~`Lv.6` 등급별 고유 테두리 색상·글로우 효과 적용.
  - 33종의 커스텀 SVG 아이템 일러스트(`frontend/public/items/*.svg`) 제작 및 적용.
- **우주 재해, 멀티유저 교전 및 해적 전용 전리품**:
  - 직접 운행 중 태양풍, 소행성/행성 파편, 우주 쓰레기 충돌 및 다른 멀티유저 함선과의 충돌 판정 구현.
  - `Lv.1`~`Lv.10` 다단계 우주해적 및 고레벨 해적 대상 다중 사용자 협동 공격(Co-op Raid) 구현.
  - 우주해적 격파 시 해적 레벨에 비례해 상점에서 구매할 수 없는 **해적 전용 전리품 5종(`pirate_only: true`)** 확률 드랍 구현.
- **Google SSO 랜딩페이지, 자산 기반 변동 레벨, 소셜/퀘스트, 다국어, 사운드**:
  - Google SSO 로그인 지원 랜딩페이지 및 관리자(`oldtv.cf@gmail.com`) 전용 퀘스트 에디터/관리 메뉴 제공.
  - 총자산(`net_worth` = 크레딧 + 화물 평가액 + 보유 아이템 가치) 증감에 따라 파일럿 레벨(`Lv.1`~`Lv.10`)이 실시간 상승·하락하도록 구현.
  - 친구 요청/수락 및 온라인 접속 상태 조회(`FriendsModal`), 레벨별 퀘스트 수행/보상 수령(`QuestModal`) 구현.
  - 영어(`en`) 기본, 한국어(`ko`), 일본어(`ja`), 중국어(`zh`) 모듈형 다국어 시스템 및 사용자 설정 DB 영구 저장 구현.
  - Web Audio API 프로시저럴 신디사이저(`SoundEngine.ts`)로 우주 배경음악 4곡 랜덤 재생 및 전투 전용 BGM·레이저/폭발/전리품 효과음 구현.

### 검증 결과
- `bun run build:frontend`: Vite + Svelte 5 + Three.js 프로덕션 번들 빌드 성공 (`dist/index.html`, CSS/JS 번들 생성 확인).
- 백엔드 통합 검증(`verify_all_multiplayer.ts`): Google SSO, 4개 국어 DB 저장, 긴급 지도 10배 과금(3회 제한), AI Agent 차감, 해적 레벨별 협동 전투 및 상점 비매품 전리품(`pirate_only`) 드랍, 친구 요청/수락, 관리자 퀘스트 에디터 API 전 항목 통과.
